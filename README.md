● Download and Install NodeJS and check for node & npm :

    ● node -v
    ● npm -v

Note - If already available on your system then ignore. To check run above commands in command prompt.


-------------------------------------------------------------------------------------


● YadByad Frontend :

    1. Install Dependencies -

        ● npm install    
        ● npm i

    2. Run Code - 

        ● npm run dev


-------------------------------------------------------------------------------------


● YadByad Backend :

    1. Install Dependencies -

        ● npm install    
        ● npm i

    2. Run Code - 

        ● npm run start
